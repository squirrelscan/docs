## What Gets Checked

- **Meta tags** - title, description, canonical, robots
- **OpenGraph & Twitter Cards** - social sharing metadata
- **Structured data** - JSON-LD validation and coverage
- **Headings** - H1-H6 hierarchy and structure
- **Links** - internal, external, and broken link detection
- **Images** - alt text, dimensions, format optimization
- **Security** - HTTPS, headers, CSP, HSTS
- **Performance** - Core Web Vitals hints
