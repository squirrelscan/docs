## Installation

Install SquirrelScan with the install script:

```bash
curl -fsSL https://squirrelscan.com/install | bash
```

This downloads the binary to `~/.local/bin/squirrel` and adds it to your PATH.

<Tip>After installation, run `squirrel self doctor` to verify everything is set up correctly.</Tip>

## Run Your First Audit

Audit a website with a single command:

```bash
squirrel audit https://example.com
```

You'll see output like:

```
SquirrelScan v0.0.4-beta

Auditing https://example.com...
├─ Crawled 12 pages
├─ Found 3 issues
└─ Health Score: 87/100

ISSUES

[high] Missing meta description on /about
[medium] Image missing alt text: /images/hero.png
[low] Non-HTTPS link on /contact
```

## Common Options

<Steps>
  <Step title="Limit pages crawled">
    For large sites, limit pages to get faster results:
    ```bash
    squirrel audit https://example.com -m 10
    ```
  </Step>

  <Step title="Export to JSON">
    Output machine-readable JSON for CI/CD or AI processing:
    ```bash
    squirrel audit https://example.com -f json -o report.json
    ```
  </Step>

  <Step title="Generate HTML report">
    Create a visual HTML report:
    ```bash
    squirrel audit https://example.com -f html -o report.html
    ```
  </Step>

  <Step title="Deep audit mode">
    Enable all extended checks including external links:
    ```bash
    squirrel audit https://example.com -d
    ```
  </Step>
</Steps>

## What Gets Checked

| Category | Checks |
|----------|--------|
| **SEO** | Title, description, canonical, robots.txt, sitemap |
| **Social** | OpenGraph, Twitter Cards |
| **Content** | Headings, word count, thin content |
| **Links** | Broken links, redirects, external links |
| **Images** | Alt text, dimensions, lazy loading |
| **Schema** | JSON-LD validation, schema types |
| **Security** | HTTPS, CSP, HSTS, mixed content |
| **Performance** | Preload hints, Core Web Vitals signals |

## Using with Claude Code

SquirrelScan is designed for AI agents. Pipe JSON output directly to your LLM:

```bash
squirrel audit https://example.com -f json | claude
```

Or use it as an MCP server for Claude Code integration.
