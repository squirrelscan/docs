Checks linked PDF sizes against Googlebot 64MB truncation limit

| | |
|---|---|
| **Rule ID** | `crawl/pdf-size` |
| **Category** | [Crawlability](/rules/crawl) |
| **Scope** | Site-wide |
| **Severity** | warning |
| **Weight** | 4/10 |

## Solution

Googlebot truncates PDFs at 64MB—content beyond that limit is ignored during indexing. Split large documents into smaller parts, compress images within PDFs, or add a noindex X-Robots-Tag header if the PDF doesn't need to appear in search results.

## Options

This rule supports the following configuration options:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `max_bytes` | unknown | `undefined` | Max PDF byte size before Googlebot truncates |
| `max_pdfs_to_check` | unknown | `undefined` | Maximum number of PDF links to check |

### Configuration Example

```toml squirrel.toml
[rules."crawl/pdf-size"]
max_bytes = undefined
max_pdfs_to_check = undefined
```

## Enable / Disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["crawl/pdf-size"]
```

### Disable all Crawlability rules

```toml squirrel.toml
[rules]
disable = ["crawl/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["crawl/pdf-size"]
disable = ["*"]
```
