Checks that toggle fields (checkbox, radio, switch) have accessible names

| | |
|---|---|
| **Rule ID** | `a11y/aria-toggle-field-name` |
| **Category** | [Accessibility](/rules/a11y) |
| **Scope** | Per-page |
| **Severity** | Error |
| **Weight** | 7/10 |

## Solution

Toggle fields need accessible names to describe what they control. Use one of the following:

- `<label for="id">` with matching id
- `aria-label` attribute
- `aria-labelledby` referencing a visible label
- Wrap the input in a `<label>` element

**Example:**
```html
<label><input type="checkbox"> Subscribe to newsletter</label>
```

## Enable / Disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["a11y/aria-toggle-field-name"]
```

### Disable all Accessibility rules

```toml squirrel.toml
[rules]
disable = ["a11y/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["a11y/aria-toggle-field-name"]
disable = ["*"]
```
