Checks the total byte weight of the page

| | |
|---|---|
| **Rule ID** | `performance/total-byte-weight` |
| **Category** | [Performance](/rules/perf) |
| **Scope** | Per-site |
| **Severity** | warning |
| **Weight** | 6/10 |

## Solution

Reduce total page weight for faster loads on slow connections:

- Optimize images (use modern formats, compress, serve appropriate sizes)
- Minify and compress CSS/JS
- Remove unused code via tree-shaking
- Lazy-load non-critical resources
- Target under 1.6MB for mobile users

## Options

This rule supports the following configuration options:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `warn_threshold_kb` | number | `1600` | Warning threshold for total page weight in KB |
| `error_threshold_kb` | number | `5000` | Error threshold for total page weight in KB |

### Configuration Example

```toml squirrel.toml
[rules."performance/total-byte-weight"]
warn_threshold_kb = 1600
error_threshold_kb = 5000
```

## Enable / Disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["performance/total-byte-weight"]
```

### Disable all Performance rules

```toml squirrel.toml
[rules]
disable = ["perf/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["performance/total-byte-weight"]
disable = ["*"]
```
