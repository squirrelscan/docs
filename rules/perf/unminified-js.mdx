Detects unminified JavaScript that could be optimized

| | |
|---|---|
| **Rule ID** | `performance/unminified-js` |
| **Category** | [Performance](/rules/perf) |
| **Scope** | Per-page |
| **Severity** | warning |
| **Weight** | 5/10 |

## Solution

Minify JavaScript to reduce file size and improve load times:

- Use build tools like Terser, esbuild, or UglifyJS
- Most bundlers (Webpack, Vite, Rollup) minify automatically in production
- Minification shortens variable names, removes whitespace, and dead code

## Options

This rule supports the following configuration options:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `min_size_kb` | number | `5` | Minimum JS size in KB to check for minification |

### Configuration Example

```toml squirrel.toml
[rules."performance/unminified-js"]
min_size_kb = 5
```

## Enable / Disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["performance/unminified-js"]
```

### Disable all Performance rules

```toml squirrel.toml
[rules]
disable = ["perf/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["performance/unminified-js"]
disable = ["*"]
```
