Checks for Gzip or Brotli compression

| | |
|---|---|
| **Rule ID** | `performance/compression` |
| **Category** | [Performance](/rules/perf) |
| **Scope** | Per-page |
| **Severity** | warning |
| **Weight** | 6/10 |

## Solution

Enable Gzip or Brotli compression on your server to reduce transfer sizes by 60-90%. Most web servers support this via configuration:

- **nginx**: `gzip on;`
- **Apache**: `AddOutputFilterByType DEFLATE text/html`
- Brotli provides better compression than Gzip for text content

## Enable / Disable

### Disable this rule

```toml squirrel.toml
[rules]
disable = ["performance/compression"]
```

### Disable all Performance rules

```toml squirrel.toml
[rules]
disable = ["perf/*"]
```

### Enable only this rule

```toml squirrel.toml
[rules]
enable = ["performance/compression"]
disable = ["*"]
```
